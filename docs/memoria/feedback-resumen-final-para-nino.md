# Cada mensaje termina con un resumen "para un niño"

Pedido textual del dueño (2-sep-2026): *"Al final siempre de cada mensaje me vas a dejar una
conclusión o resumen con palabras sencillas y ejemplos como si fuera para un niño."*

**Why:** el dueño no es técnico y las respuestas largas de arquitectura lo dejan sin saber qué
decidir. Ya había pedido antes explicaciones simples ([[feedback-explicaciones-simples]]); ahora
lo formaliza: no basta con explicar simple en el cuerpo, **el cierre tiene que ser una versión
para niño** — una analogía o ejemplo concreto y la conclusión en dos o tres frases.

**How to apply:**
- Al final de CADA mensaje (no solo los largos), un bloque final con título tipo
  "En palabras sencillas" / "Resumen para llevar".
- Analogía concreta o ejemplo con nombres reales (ERICK, la DQG87I, Brandon), nunca abstracto.
- Dos o tres frases. Si hay una decisión que él tiene que tomar, decirla ahí.
- Esto se suma a las otras reglas de comunicación, no las reemplaza: [[feedback-explicaciones-simples]],
  [[regla-no-romper-lo-que-funciona]] (explicar y confirmar que entendió ANTES de tocar).
